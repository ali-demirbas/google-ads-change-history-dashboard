Ads Change History

What this report can't do
  • Only knows what's in the input file — doesn't call the Google Ads API live, doesn't know about changes made after the export or outside its date range.
  • Reports what changed and when — never whether a change was good, risky, or should have happened differently. That judgment isn't in scope for this tool.
  • If the input includes Google Ads ChangeEvent API data: that API keeps only 30 days of history, caps at 10,000 rows per query, can lag up to ~3 minutes behind a very recent change, and may not include every entry the Google Ads UI's own Change History page shows.
